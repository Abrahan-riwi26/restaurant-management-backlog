# HU-016 — Gestión de Empleados

**Épica**
Gestión de Usuarios

**Sprint**
Sprint 3

**Prioridad**
Muy Alta

**Story Points**
13

**Dependencias**
HU-015 — Inicio de Sesión y Autenticación

## Historia de Usuario

**Como** administrador del restaurante

**Quiero** registrar y administrar empleados

**Para** controlar qué colaboradores pueden acceder y operar dentro del sistema.

## Objetivo

Permitir la gestión de empleados que utilizarán la plataforma para realizar funciones administrativas y operativas.

## Descripción Funcional

El administrador podrá:

* Registrar empleados.
* Consultar empleados.
* Actualizar información.
* Activar o desactivar cuentas.

Cada empleado deberá contener:

* Nombre.
* Apellido.
* Correo.
* Teléfono.
* Cargo.
* Estado.

Estados:

* `ACTIVE`
* `INACTIVE`

## Flujo

Registrar Empleado
↓
Validar Información
↓
Validar Correo Único
↓
Asignar Cargo
↓
Crear Cuenta
↓
Guardar Empleado

## Reglas de Negocio

**RN-095**
El correo electrónico deberá ser único.

**RN-096**
Todo empleado deberá tener un cargo asignado.

**RN-097**
Todo empleado nuevo iniciará con estado `ACTIVE`.

**RN-098**
Un empleado `INACTIVE` no podrá iniciar sesión.

## Endpoints

```http
POST /api/v1/employees
GET /api/v1/employees
GET /api/v1/employees/{id}
PATCH /api/v1/employees/{id}
PATCH /api/v1/employees/{id}/status
```

## Validaciones

* Nombre obligatorio.
* Correo válido y único.
* Cargo obligatorio.
* Estado válido.

## Criterios de Aceptación

* Se puede registrar un empleado.
* No se permiten correos duplicados.
* Se pueden consultar y actualizar empleados.
* Se puede activar o desactivar una cuenta.
* Un empleado inactivo no puede autenticarse.
