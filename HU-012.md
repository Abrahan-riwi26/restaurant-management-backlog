# HU-012 — Check-in del Cliente

**Épica**
Gestión de Reservas

**Sprint**
Sprint 2

**Prioridad**
Muy Alta

**Story Points**
8

**Dependencias**
HU-007 — Registro de Reserva
HU-011 — Confirmación de Reserva

## Historia de Usuario

**Como** personal autorizado del restaurante

**Quiero** registrar la llegada de un cliente con reserva

**Para** confirmar su asistencia y habilitar la mesa asignada para iniciar la atención.

## Objetivo

Permitir que el personal del restaurante registre el check-in de una reserva confirmada cuando el cliente llegue al establecimiento.

## Descripción Funcional

El personal autorizado deberá poder consultar una reserva confirmada y registrar la llegada del cliente.

Al realizar el check-in:

* La reserva cambiará de `CONFIRMED` a `CHECKED_IN`.
* La mesa asignada cambiará a estado `OCCUPIED`.
* La fecha y hora de llegada deberán quedar registradas.
* La reserva quedará preparada para iniciar posteriormente un pedido asociado a la mesa.

## Flujo

Consultar Reserva
↓
Validar Estado
↓
Registrar Llegada
↓
Cambiar Reserva a `CHECKED_IN`
↓
Cambiar Mesa a `OCCUPIED`
↓
Registrar Fecha y Hora
↓
Mostrar Confirmación

## Reglas de Negocio

**RN-070**
Solo podrán realizar check-in las reservas existentes.

**RN-071**
Solo podrán realizar check-in las reservas con estado `CONFIRMED`.

**RN-072**
La reserva deberá tener una mesa asignada.

**RN-073**
Al realizar el check-in, la mesa deberá cambiar a estado `OCCUPIED`.

**RN-074**
La fecha y hora del check-in deberán quedar registradas.

**RN-075**
No se permitirá realizar check-in sobre reservas `CANCELLED`, `NO_SHOW`, `CHECKED_IN` o `COMPLETED`.

## Endpoint

```http
PATCH /api/v1/reservations/{id}/check-in
```

## Validaciones

* Reserva existente.
* Estado `CONFIRMED`.
* Mesa asignada.
* Identificador válido.

## Criterios de Aceptación

* Se puede registrar el check-in de una reserva confirmada.
* La reserva cambia a estado `CHECKED_IN`.
* La mesa cambia automáticamente a `OCCUPIED`.
* La fecha y hora de llegada quedan almacenadas.
* No se permite realizar check-in sobre reservas con estados no válidos.
* La reserva queda disponible para iniciar posteriormente la atención mediante un pedido.
