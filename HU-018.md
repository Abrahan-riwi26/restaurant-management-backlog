# HU-018 — Recuperación de Contraseña

**Épica**
Seguridad y Autenticación

**Sprint**
Sprint 3

**Prioridad**
Alta

**Story Points**
8

**Dependencias**
HU-015 — Inicio de Sesión y Autenticación

## Historia de Usuario

**Como** usuario registrado

**Quiero** recuperar mi contraseña cuando la olvide

**Para** volver a acceder a mi cuenta de forma segura.

## Objetivo

Permitir el restablecimiento seguro de contraseñas mediante un mecanismo temporal de recuperación.

## Descripción Funcional

El usuario podrá solicitar la recuperación mediante su correo electrónico.

El sistema deberá:

* Generar un token temporal.
* Asociarlo al usuario.
* Establecer una fecha de expiración.
* Permitir definir una nueva contraseña.
* Invalidar el token después de utilizarlo.

## Flujo

Solicitar Recuperación
↓
Validar Usuario
↓
Generar Token Temporal
↓
Enviar Recuperación
↓
Ingresar Nueva Contraseña
↓
Validar Token
↓
Actualizar Contraseña

## Reglas de Negocio

**RN-103**
El token de recuperación deberá tener tiempo de expiración.

**RN-104**
Un token solo podrá utilizarse una vez.

**RN-105**
La nueva contraseña deberá cumplir la política de seguridad.

**RN-106**
La nueva contraseña deberá almacenarse de forma segura.

## Endpoints

```http
POST /api/v1/auth/forgot-password
POST /api/v1/auth/reset-password
```

## Validaciones

* Correo válido.
* Token válido y vigente.
* Contraseña mínima de 8 caracteres.
* Confirmación de contraseña coincidente.

## Criterios de Aceptación

* Se puede solicitar recuperación de contraseña.
* Se genera un token temporal.
* Los tokens expirados son rechazados.
* El token no puede reutilizarse.
* La contraseña se actualiza correctamente.
* El usuario puede autenticarse con la nueva contraseña.
