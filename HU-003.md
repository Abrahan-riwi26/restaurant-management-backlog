# HU-003 — Administración de Categorías del Menú

**Épica**
Gestión del Menú

**Sprint**
Sprint 1

**Prioridad**
Alta

**Story Points**
8

## Historia de Usuario

**Como** administrador del restaurante

**Quiero** crear y administrar categorías del menú

**Para** organizar correctamente los productos disponibles para los clientes.

## Objetivo

Permitir la clasificación de los productos del restaurante mediante categorías que faciliten la administración y consulta del menú.

## Descripción Funcional

El administrador podrá crear, consultar y actualizar categorías del menú.

Cada categoría deberá contener:

* Nombre.
* Descripción.
* Estado.

Ejemplos de categorías:

* Entradas.
* Platos fuertes.
* Bebidas.
* Postres.
* Hamburguesas.
* Ensaladas.

Estados disponibles:

* `ACTIVE`
* `INACTIVE`

Solo las categorías activas podrán utilizarse para mostrar productos dentro del menú disponible para clientes.

## Flujo

Crear Categoría
↓
Validar Información
↓
Validar Nombre Único
↓
Guardar Categoría
↓
Mostrar Categoría Creada

## Reglas de Negocio

**RN-021**
El nombre de la categoría deberá ser único.

**RN-022**
Toda categoría nueva iniciará con estado `ACTIVE`.

**RN-023**
Una categoría `INACTIVE` no deberá mostrarse dentro del menú disponible para clientes.

**RN-024**
Solo podrán utilizarse estados definidos por el sistema.

## Endpoints

```http
POST /api/v1/categories
GET /api/v1/categories
GET /api/v1/categories/{id}
PATCH /api/v1/categories/{id}
PATCH /api/v1/categories/{id}/status
```

## Validaciones

* Nombre obligatorio.
* Nombre único.
* Nombre con longitud válida.
* Estado válido.

## Criterios de Aceptación

* Se puede registrar una categoría correctamente.
* No se permiten nombres duplicados.
* Se puede consultar el listado de categorías.
* Se puede consultar una categoría específica.
* Se puede actualizar una categoría.
* Se puede activar o desactivar una categoría.
* Las categorías inactivas no se muestran en el menú público.
* Los datos quedan almacenados en PostgreSQL.
